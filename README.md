# Laundry Wallah / Laundry Mart

This project is a simple single-page website for a laundry service called Laundry Wallah / Laundry Mart.

## Project Overview

The project uses plain HTML to display a landing page with key business information:

- A welcome header with the service name.
- An about section describing the laundry service.
- A service list showing available offerings.
- A price list table with basic rates.
- A booking form to collect customer contact details.
- A footer with contact information.

## How It Was Made

- Built using only HTML (`index.html`).
- The page is structured using semantic sections: header, section, table, form, and footer.
- Images are embedded via an external `src` URL.
- No CSS or JavaScript files are included in this version.

## Files

- `index.html` — the main web page for Laundry Wallah.

## Usage

1. Open `index.html` in a web browser.
2. Review the content and edit text, services, or pricing as needed.
3. Add CSS or JavaScript later to improve styling and interactivity.

## Notes

- This is a starter landing page for a laundry business.
- It can be extended with styling, validation, and backend booking functionality.
